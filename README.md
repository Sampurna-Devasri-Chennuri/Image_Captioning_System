# Image Captioning AI

A professional, production-ready AI Image Captioning system built with Flask and Salesforce's BLIP model.

## Features
- **Auto-Captioning**: Uses Transformers to generate human-like descriptions.
- **Modern UI**: Apple-inspired dark glassmorphism design.
- **Production-Ready**: No empty files, no placeholder weights.
- **Auto-Model Loading**: Automatically downloads pre-trained weights from Hugging Face on the first run.
